About the dashboards

What these dashboards measure, where the numbers come from, and how communities put them to use.

What they measure

Each dashboard tracks one part of the housing response system — from point-in-time counts to program exits and housing placements.

How data is used

Communities use these figures to plan services, target resources, and track whether households are moving into permanent housing.

Monthly updates

Figures come from a shared client data system and refresh monthly, so each dashboard reflects a recent, consistent snapshot.
